TidyFolder: Automated File OrganizerTidyFolder is a Python-based utility that automatically sorts files in a selected directory into organized sub-folders. Stop hunting through hundreds of files and let automation handle your digital housekeeping.🚀 FeaturesSmart Categorization: Automatically groups files into Images, PDFs, Audio, and Video categories.Catch-all Sorting: Any unrecognized file types are safely moved to an Others folder.One-Click Undo: Made a mistake? The script logs every move, allowing you to revert the entire organization process instantly.User-Friendly Selection: Uses a native system folder picker—no need to manually type out long file paths.Lightweight: Zero heavy dependencies; uses standard Python libraries.🛠️ InstallationClone the repository:Bashgit clone https://github.com/yourusername/tidyfolder.git

cd tidyfolder

Ensure Python is installed:This script requires Python 3.x.No pip install required:The script uses tkinter, os, and shutil, which are included in the Python Standard Library.📖 How To UseRun the script from your terminal:Bashpython main.py

Options:Organize (o):A folder selection window will appear.Select the directory you want to clean up.The script will create sub-folders and move files accordingly.Undo (u):The script reads undo\_log.json to move all files back to their original locations and deletes the sub-folders' references.📂 Default CategoriesCategoryExtensions SupportedImages.jpg, .jpeg, .pngPDFs.pdfAudio.mp3, .wavVideos.mp4, .mkvOthersAll other file typesNote: You can easily add more formats by editing the TYPES dictionary in main.py.⚠️ Safety FirstDirectory Protection: The script skips sub-directories to prevent recursive moving loops.Transaction Log: The undo\_log.json file is created in the script's root directory. Do not delete this file if you plan on undoing your last organization task.
